SpeedCrunch snapshot packages

This is personal packaging of the upstream SpeedCrunch calculator, not a fork or a new upstream project.

Pinned upstream revision: 05d4f0f78e2b0646c4529adb1dad2453b378c736.

macOS (Homebrew)

brew tap dirtycold/speedcrunch
brew install --cask speedcrunch

Linux (Flatpak)

Install from the Flatpak reference, or run:

flatpak remote-add --if-not-exists --user --no-gpg-verify speedcrunch \
  https://dirtycold.github.io/homebrew-speedcrunch/repo/
flatpak install --user speedcrunch org.speedcrunch.SpeedCrunch
Packages are built from the pinned source snapshot and are not official upstream releases.
